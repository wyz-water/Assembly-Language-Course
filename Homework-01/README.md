# Homework 01 - Hello Program Analysis

Analyze the "Hello world" program written in assembly language.

## Tasks

1. Implement two versions that load the string address with `LEA` and `MOV offset`, then compare the two approaches.
2. Generate and analyze the listing file (`.lst`) and the cross-reference file (`.crf` -> `.ref`).
3. Execute the program by writing the machine code directly into memory with DEBUG.
