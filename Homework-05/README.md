# Homework 05 - Fibonacci (Recursion)

Compute the n-th Fibonacci number F(n) = F(n-1) + F(n-2), where F(0) = 0 and F(1) = 1.

## Tasks

1. Read n from the keyboard and output F(n).
2. Implement the recursion with arguments passed in registers.
3. Initialize the stack space and analyze how large it must be to avoid stack overflow.
4. Single-step the program and observe how the stack changes on each call and return.
5. Implement in C and analyze the disassembly.
