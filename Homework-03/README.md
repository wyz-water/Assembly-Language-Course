# Homework 03 - Sum

Compute the sum 1 + 2 + ... + 100 and print the result (5050) to the screen.

## Tasks

1. Implement the sum and try storing the result in a register, in the data segment, and on the stack.
2. Read a number (1-100) from the user and output the sum in decimal.
3. Implement in C and analyze the disassembly.
