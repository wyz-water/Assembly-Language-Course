# Homework 04 - Multiplication Table Debugging

Check the 9x9 multiplication table data and print the positions of the wrong values.

## Tasks

1. Implement the check with a procedure call (`CALL` / `RET`), saving and restoring the caller's registers inside the procedure.
2. Implement the nested double loop and access the table with indexed addressing in the data segment.
3. Implement in C and analyze the disassembly, comparing data defined as global and local.
