# Homework 06 - Calendar

Print the calendar of a given year (1900-2099) and month (1-12).

## Tasks

1. Read the year and month from the keyboard and print the monthly calendar.
2. Package the logic into procedures and pass parameters via registers, the data segment, and the stack.
3. Use at least two code segments and handle far calls and jumps between segments.
4. Mind the -128 ~ +127 range of conditional jumps and compare short, near, and far jumps.
5. Implement in C and analyze the disassembly.
